# My Monthly Expenses — iPhone Web App

This is a private, offline-friendly expense tracker designed for iPhone.

## Features
- CAD currency
- Monthly income, expenses, and balance
- Expense categories
- Yearly spending chart
- Add and delete transactions
- Data saved locally on the device
- Installable on the iPhone Home Screen

## Important
Opening `index.html` directly from the Files app will not provide full app behavior.
Upload this folder to a static web host first.

Easy hosting choices:
1. GitHub Pages
2. Netlify Drop
3. Cloudflare Pages

## Add to iPhone Home Screen
1. Open the hosted website in Safari.
2. Tap the Share button.
3. Tap **Add to Home Screen**.
4. Tap **Add**.

Your financial data remains in Safari's local storage on that device and is not sent to a server.
